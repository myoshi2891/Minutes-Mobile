# MinutesMobile

iPhone だけで会議を録音し、端末の外へデータを送らずに文字起こしまで行う議事録アプリ。PC/Web 版 Minutes の原則（Recording is Source of Truth / Zero External Data Egress）を iOS へ移植する。

現在の状態: 要件定義（2026-11-14 初版）。実装は未着手。
